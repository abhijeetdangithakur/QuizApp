# Quiz App

This is a simple Quiz Application made using HTML, CSS, and JavaScript.

## How It Started

I created this project to practice frontend web development using only basic web technologies without any libraries or frameworks.

## Features

- Multiple choice questions
- Score display after quiz
- Responsive design
- Restart option

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the project.
2. Open the `index.html` file in any browser.
3. The quiz will start and you can play!

## No External Dependencies

This app does not use any external libraries or tools.
